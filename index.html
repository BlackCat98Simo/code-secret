    LE PRINCIPE

    Un peu de méthode,
    un déclic de logique.

    1. Retrouvez un code de 4 couleurs parmi les six ci-dessous. Une couleur peut se répéter.
    2. Composez une proposition, puis validez. Vous disposez de 10 essais.
    3. Utilisez les deux indices pour déduire le code. Ils ne révèlent aucune position.

    Bien placée
    Bonne couleur, bonne position.

    Mal placée
    Bonne couleur, autre position.

    Chaque pion compte une seule fois : les bien placés d’abord, puis les mal placés parmi les pions restants.

    Les six couleurs

    Clavier et règles de fin

    Tab pour parcourir les commandes, flèches pour choisir une couleur, Entrée pour valider. Sur téléphone, touchez les listes de couleurs.

    Une proposition incomplète est refusée sans perdre d’essai. Quatre bien placées donnent la victoire, même au dixième essai. Sinon, après dix essais, la partie est perdue. Les propositions sont ensuite bloquées. Le code reste caché, conformément au contrat de test 0.2.

    « Nouvelle partie » tire un nouveau code et efface l’historique. Le hasard peut choisir le même code.

    Un jeu solo inspiré du Mastermind.
    Sans compte. Sans installation. Juste vous et le code.
